# Правило «Пассажир» — возможно корпоративный или Fasten
27.11.2026. Последнее решение владельца отменяет расчет по EV и диапазон ±20%.

Явный тариф в карточке, включая Электро, рассчитывается как обычно. Если написано «Пассажир» без названия тарифа, показывать «Возможно корпоративный или Fasten». Одна общая оценка для обоих возможных источников: нижняя граница по ставке Комфорт, верхняя по Комфорт+, на одном маршруте, с одинаковыми подтвержденными надбавками и доплатами. Суммы на руки рассчитывать по комиссиям соответствующих справочных тарифов; при неизвестной комиссии не выдумывать ее. Не применять ставку Электро, не считать два отдельных заказа Fasten/корпоративный. Диапазон — ориентир, не подтвержденная сетка этих сервисов. Явная фактическая цена имеет приоритет и не является первым прогнозом. Внутренний исторический флаг assumedEv означает неизвестный класс, а не подтвержденный тариф EV; исключать такие записи из обучения известных тарифов. Проверить оба сценария, все источники маршрутов, границы и отсутствие подмены фактической цены прогнозом.
